# Verification tax

Date: 2026-08
Attaches to: cv.check
Optional Coach drill: Before you call it green, name the check that would have caught today's miss.

Generation got cheaper. Checking did not. That is the whole brief.

DORA's 2026 follow-up on AI ROI names a verification tax: time saved writing code is spent auditing it, and the bill shows up before the payoff. Stack Overflow's own trust numbers moved the wrong way as usage rose. Sonar's survey of working engineers found almost nobody fully trusts AI-generated code as functionally correct, while a large share of committed code already has a model in its history. Better tools did not buy more trust. They bought more skepticism with better reasons.

Northline Desk is the same shape in miniature. The happy-path suite is green while T-1842 sits on Support. The tests exist. They do not protect. Coverage that measures optimism instead of risk is how a dashboard lies with a smile.

What that means on this node:

1. A check that only passes after the fix is incomplete until you have watched it fail on the broken state.
2. "The model said it works" is not verification. It is a proposal.
3. The stranger-runnable command is the tax paid in public. If it needs you standing next to it, you have not paid yet.

Industry names will change. The tax will not. Every hour you work with an assistant, you are already doing Verification whether you log it or not. This node makes the bill visible, and forces you to keep the receipt.
