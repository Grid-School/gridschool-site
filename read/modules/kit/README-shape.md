# README shape

A stranger will open the repository before reading the project documents. Make the first screen answer four questions:

1. What is this project? Answer in one sentence.
2. How does someone run it? Give one command or link to `LIVE.md`.
3. How does someone verify it? Give one command or link to `VERIFY.md`.
4. What can the project not do? Link to `SPEC.md`.

Then link to `SPEC.md`, `VERIFY.md`, `AGENT-LOG.md`, `LIVE.md`, `INCIDENT.md`, `DECISION.md`, and `DEMO.md`.

Describe the project’s result before listing the technology stack.
